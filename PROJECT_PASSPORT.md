# FSS - Project Passport

**Status:** Research Prototype (Stable Architecture, Pending Symmetry Discovery Engine)

## 1. Purpose
The **Fedorov Symmetry Reasoning Stand (FSS)** is an experimental engineering project for the automated, deterministic discovery and analysis of symmetry groups in crystalline structures, grounded in Fedorov's 230 space groups.

## 2. Fundamental Principles
- **Deterministic Verification**: The system is designed to provide verifiable, reproducible results, explicitly rejecting claims of "absolute" completeness in favor of rigorous, tolerance-based verification.
- **Affine Dimensionality**: Structural analysis is predicated on 3D affine dimensionality (0-3), utilizing barycenter normalization for scale and translation invariance.
- **Evidence-Based Reasoning**: All symmetry claims must be supported by evidence generated by the system, following a strict contract (`EVIDENCE_CONTRACT.md`).

## 3. Scope & Responsibilities
- **Core Engine (Deterministic)**: Handles geometry normalization, dimension assessment, and robust anchor frame construction. Status: `IMPLEMENTED`.
- **Symmetry Discovery (Proposed)**: Automated candidate search and group validation. Status: `NOT_IMPLEMENTED`.
- **UI/Integration Layer**: Visualization and shell environment. Status: `BASELINE`.

## 4. Key Distinctions
- Geometry State ≠ Epistemic State
- Claim ≠ Truth
- Construction ≠ Verification
- Representation ≠ Truth
- Producer ≠ Receiver
- Lookup ≠ Prediction
- Demo ≠ Validated System
